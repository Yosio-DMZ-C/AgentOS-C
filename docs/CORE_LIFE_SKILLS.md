# Core Life Skills — 人生の高難度判断を支えるプリインストールSkill（設計案）

- 設計状態：**Concept / Roadmap**（本書だけで利用可能な医療・法律・金融サービスや専門家紹介機能が完成したことを意味しない）
- 対象：一般配布するAgentOS-Cの任意拡張、および後日コミュニティで検証する共有Skill
- 基本原則：**判断を代行する正解集ではなく、重大な見落としを減らす初動・記録・選択・専門家接続のプレイブック**

## 1. 背景と位置付け

子育て、健康問題、メンタルヘルス、投資、住宅購入、災害、契約・法律、デジタル安全は、平時に準備するのが難しい一方、必要になってからゼロから調べると時間的余裕がないことがある。

AgentOS-Cは利用者に一から知識体系を組み立てさせない。実用性が高い初動Skillを**Core Life Skills**として用意し、必要なとき本人・家族の条件に合わせて使えることを目標とする。

OSのインストールを重くしないため、初期導入は**小さなINDEXと共通の判断・安全ガード**を基本とし、領域別プレイブック本文は必要時に取得・更新できる構造とする。実在の専門家ディレクトリや推奨アルゴリズムは現時点の必須要件としない。

## 2. 想定領域

|領域|プレイブックの例|
|---|---|
|子育て・教育|年齢別の生活習慣、食事、学び、学校トラブル、オンライン利用、相談先|
|健康・医療ナビゲーション|症状の時系列記録、見逃してはいけない徴候、検査・受診歴、相談準備、専門領域の確認|
|メンタルヘルス|負荷・睡眠・行動変化の記録、初動の支援、相談・支援への接続|
|家計・投資・住宅|高額意思決定の前提整理、リスク、比較、見落とし、専門家への質問|
|災害・事故|準備、初動、状況整理、連絡、証拠・手続きの記録|
|契約・法律・消費者|期限、証拠保全、相談先、資格・地域管轄の確認|
|デジタル安全|乗っ取り・紛失時の初動、復旧、権限、バックアップ|

この表は対象候補であり、各領域の完成済みSkillを示していない。

## 3. 三層モデル

1. **Core Skills（標準知）**：多くの人に共通する初動、確認事項、記録方法、リスク分岐。レビュー済みのものだけを標準配布候補とする。
2. **Community Skills（共有知）**：複数の専門家・利用者・資料から集まる知見、失敗例、更新提案。出典、検証、改訂、撤回を管理する。人気や投稿数だけでは採用しない。
3. **Personal Skills / Context（個人適合）**：本人・家庭・地域の条件、既往歴や過去の判断、希望、実施結果に応じた適用。個人情報は非公開が既定で、共有知への自動逆流は禁止する。

共有文書と個人用正本は別ノードとして管理し、Personal層からCommunity層へ知識を出す場合は、本人の明示承認、再同定リスク検査、利用許諾、出典確認を行う。

## 4. 集合知の扱い

「集合知」は**多数決による正解確定**を意味しない。質の高い一次資料・診療ガイドライン・系統的レビュー・専門家の独立した意見などを、適用対象や限界つきで照合するという意味で用いる。

共有Skillには、少なくとも次の情報を持たせる。

- 出典と引用位置、発行日・取得日、地域、適用条件、対象集団
- 根拠の強さ、方法論上の限界、利益相反、反証・異論
- 更新期限、Reviewer、版、変更理由、採用状態（Draft / Reviewed / Active / Disputed / Retracted 等）
- 成功談・失敗談は事例として区別し、一般化された効果と混同しない
- 専門家の見解が割れる場合は、何が不明で判断が変わる条件は何かを明示する

**複数の意見より、独立性と根拠の質を優先する。** 利用者の個別条件に合わない多数派見解を機械的に適用しない。

## 5. 個人条件との照合 → 専門家の見解へつなぐ（将来拡張）

目標のフロー：

```text
一般公開の根拠・共有Skill
        ↓
利用者の状況・履歴・希望・未確認点を整理
        ↓
適用条件の照合・リスクの見落とし確認
        ↓
適切な専門領域と相談先候補の提示
        ↓
本人が選んだ専門家への相談準備
        ↓
実際に得た見解・検査・判断を出典付きで保存
        ↓
必要に応じてPersonal Skillを改善
```

特に医療では、AIが確定診断や専門医の資格・受け入れ状況を推測しない。状況に応じて緊急の対応が必要かを優先確認し、その後に該当する診療科や専門領域、確認済みの実在する専門家・医療機関の候補へ案内する。専門家の見解が必要な場面では、相談時に共有する要約、時系列、質問、未確認事項を準備する。

**専門家の資格・専門性・所在・連絡方法・対応可否は、利用可能な正式情報で確認した範囲のみ表示する。** 候補の一致度は参考情報であり、最適・信頼できる・受診可能と保証しない。医師、心理職、法律家、金融専門職など、資格や職域が異なる専門家を同列に扱わない。

外部への予約、紹介依頼、相談文の送信、資料提出、個人情報の開示は、いずれも利用者による選択と明示的な承認を必要とする。相談が実施されていない段階で「専門家確認済み」と記録しない。

## 6. 各Skillの最低契約

既存の「個別手順書の契約」に加え、高影響領域では次を必須とする。

- **対象と対象外**：年齢、地域、条件、適用できないケース
- **最初の判断**：何が急を要するか、分岐、必要な最小質問
- **今すぐできる操作**：数分〜当日にできる、具体的で実行可能な手順
- **記録・参照**：本人の発言・現物・検査結果・AI推論を分離
- **根拠の状態**：検証済みと仮説、反証、更新予定
- **専門家接続**：相談が望ましい条件、専門領域、持参する情報
- **出力・停止・レビュー**：出した成果物、未実行、ユーザー承認が必要な行為
- **フィードバック**：実施結果をPersonal側にのみ記録し、匿名化・採用審査なしに共有へ昇格させない

「効果がありそう」「多くの人が言う」「AIが推奨した」だけで確定した効果や本人の意思決定へ昇格させない。

早期の動作検証を優先し、全分野を一括インストールしたり、確認できない品質を「標準」として配布しない。

## 8. 既存AgentOS-Cとの接続

- 標準/共有Skill：公開用リポジトリまたは審査済み共有ストレージ
- 個人適用版：個人KBの `50_skills/`、`30_contexts/`、`01_private/` 等（既存フォルダやIDを維持）
- 正本：配布パッケージ、共有Skill、Personal KBはそれぞれ正式保存先と版を区別し、無断同期・無断公開しない
- 起動：`実行` → 保存先 → 接続確認 → 推奨案 → `進めて` を変更しない
- ファイル受渡し：直接読書き不可のAIでは必要なSkillだけをパッケージ化し、初期ZIPを肥大化させない
- 品質ゲート：出典・対象条件・資格確認・相談実施確認・プライバシーに失敗したものは「Active」にしない

本書は**機能の仕様・将来像の共有**であり、診療・相談・専門家予約・外部サービス連携を実装済みだと主張するものではない。

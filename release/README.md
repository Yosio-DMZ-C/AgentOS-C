# AgentOS-C v0.1.0

AgentOS-Cの初回配布パッケージ用メタデータです。

この `release/` ディレクトリには、現在READMEとmanifestを置いています。実際の配布ZIPは、設計書・QUICKSTART・README・LICENSE・manifestをまとめた搬送用スナップショットとして扱います。

## 使い方

目的に合う設計書をAIへ渡し、次を送ります。

```text
実行
```

AIが保存先と実際の読書き能力を確認し、

- 実際に直接読書き可能と確認できた場合のみ展開Workspace
- 直接読書き不可の場合は**KB構築＋外部バックアップ**（可能ならZIP、不可なら復元可能な単一Markdown/TXT）
- その後のZIP往復更新・AI間移植は別途実機テストに成功した環境だけの拡張

のどちらかで構築します。

「AI無課金ユーザー版」という名称は料金判定ではなく、主に直接クラウド書込が使えない環境向けの導入モードです。**初回ZIPの生成・取得をすべての無料AIに保証するものではありません。** 本リポジトリにあるv0.1.0のmanifestと旧SHA-256は過去の配布スナップショットを指し、本説明更新に合わせて新しい配布ZIPを作成したわけではありません。
